# axonometric

The words this project uses for its maps. Use them in code, tests, issues and docs.

- **Map.** What axonometric makes, one per system.
- **Home folder.** The folder that holds a map's source files.
- **Structure.** One component on the map, drawn as a box.
- **Hop.** One arrow from a structure to a structure, with a label and an example payload.
- **Flow.** A named, ordered list of hops.
- **Chapter.** One step of the walkthrough. It reveals some structures and plays some hops.
- **Group.** A named set of structures.
- **Zone.** The outline drawn around a group's structures.
- **Iso view.** The isometric drawing of the layout.
- **Plan view.** The same layout drawn straight from above.
- **Status.** Whether a structure is `live`, `planned` or `off`.
- **Layout change.** A move, resize or reroute.
- **Meaning change.** Any edit to the map that isn't a layout change.
- **Pending change.** An edit that hasn't been accepted.
- **Proposal.** A pending meaning change, note, answer or text suggestion, recorded for the agent.
- **Batch.** The proposals frozen by one press of "Ready for review".
- **Verdict.** The agent's decision on one proposal: accepted, changed or rejected, with a reason.
- **Revision.** An accepted state saved in history.
